# NODE//COMMONS — сайт в стиле eDEX-UI (тема blade)

Адаптивный некоммерческий сайт на чистом HTML5 + CSS3 + Vanilla JS. Дизайн, CSS-правила,
шрифты, иконки и звуки перенесены из [eDEX-UI](https://github.com/GitSquared/edex-ui) (тема `blade`)
и адаптированы для обычного браузера.

## Запуск

Сборка и зависимости не нужны. Откройте `index.html` прямо в браузере (работает через `file://`)
или через любой статический сервер, например:

```bash
python3 -m http.server 8080
```

```

                        телеметрия узлов, консоль, вкладки, модалки, мобильное меню, звуки
assets/                 шрифты, иконки, звуки, тема, augmented-ui (см. assets/ATTRIBUTION.md)
LICENSE                 GPL-3.0
```

## Что адаптировано относительно eDEX-UI

* Размеры в `vh` (окно Electron 1920×1080 без прокрутки) пересчитаны через единицу `--u`
  (1vh при 1080p = 10.8px), поэтому пропорции совпадают с оригиналом, но страница скроллится.
* `position: absolute/fixed` колонок и терминала заменены на CSS Grid.
* Весь код с Electron/Node.js (`require`, `fs`, `ipc`, `systeminformation`, `node-pty`, `xterm`)
  удалён. Виджеты переписаны на браузерных API (Battery, Network Information, `navigator.*`),
  а данные, которые браузер не отдаёт, генерируются как демо.
* Лог загрузки встроен прямо в JS, чтобы сайт работал через `file://` без `fetch`.
* Анимация загрузки показывается один раз за сессию, её можно пропустить (Esc / клик),
  и она отключается при `prefers-reduced-motion`.

## Как поменять контент

* Тексты страницы лежат в `index.html`.
* Узлы для таблицы статуса задаются в массиве `NODES` в `js/ui-effects.js`; чтобы подключить
  реальный мониторинг, замените тело `tickTelemetry()` на запрос к своему API.
* Тексты файлов в разделе «Документация» лежат в объекте `DOCS` в `js/ui-effects.js`.
* Цвета темы — CSS-переменные `--color_r/g/b`, `--color_light_black`, `--color_grey`
  в `css/blade-theme.css`.
