# NEXUS//DEV — портал инди-разработки в стиле eDEX-UI (тема blade)

Ядро единой некоммерческой экосистемы инди-проектов на чистом HTML5 + CSS3 + Vanilla JS:
один аккаунт NEXUS ID, центр загрузок сборок (лаунчер, моды Minecraft, сборки Unreal Engine 5),
доступ к закрытым тестам и игровым серверам.

Дизайн, CSS-правила, шрифты, иконки и звуки перенесены из
[eDEX-UI](https://github.com/GitSquared/edex-ui) (тема `blade`) и адаптированы для браузера.

## Запуск

Сборка и зависимости не нужны. Откройте `index.html` прямо в браузере — все четыре страницы
работают и ссылаются друг на друга через `file://`. Можно и через любой статический сервер:

```bash
python3 -m http.server 8080
```

## Страницы

| Файл | Что внутри |
|------|-----------|
| `index.html` | «Ядро экосистемы»: центрированный hero с объяснением сайта и двумя кнопками — `ПЕРЕЙТИ К ПРОЕКТАМ` и `ВОЙТИ В СИСТЕМУ / РЕГИСТРАЦИЯ` (после входа ведёт в кабинет), блок «Как это работает» (01 // ЕДИНЫЙ АККАУНТ, 02 // ЦЕНТР ЗАГРУЗОК, 03 // СТАТУС И ТЕСТЫ) и компактная строка статуса (SYSTEM ONLINE, серверы, число доступных релизов, игроки, ссылка в кабинет). Проектов на главной нет |
| `projects.html` | Центр загрузок: фильтр ВСЕ / ДОСТУПНО / ЗАКРЫТЫЙ ТЕСТ / В РАЗРАБОТКЕ, карточки с векторной HUD-графикой, бейджем статуса, версией, размером и платформой. `СКАЧАТЬ СБОРКУ` запускает симуляцию загрузки с HUD-прогрессом (CONNECTING → DOWNLOADING → VERIFYING SHA-256 → COMPLETE, можно отменить) или, если не хватает допуска, ведёт на вход / в кабинет. `Подробнее` — окно с требованиями и patch notes. Прямая ссылка: `projects.html#bastion` |
| `dashboard.html` | Личный кабинет: вкладки «Профиль и доступ» (аватар, ID, уровень допуска, матрица доступа, сборки и история загрузок), «Управление серверами» (ONLINE/OFFLINE, ping, CPU/RAM, кнопки «Перезапуск» и «Логи»), «Настройки HUD». Гостю показывается экран ACCESS RESTRICTED |
| `auth.html` | Вход / регистрация: вкладки `LOGIN // ВХОД` и `REGISTER // РЕГИСТРАЦИЯ`, кастомные чекбоксы, проверка полей, кнопка «ТЕСТОВЫЙ ВХОД (DEMO ACCESS)», баннеры ACCESS GRANTED / DENIED и переход в кабинет |

## Структура

```
index.html, projects.html, dashboard.html, auth.html
css/blade-theme.css     тема blade: переменные из blade.json, шрифты, сетка-фон, панели, вкладки,
                        кнопки, экран загрузки, модалки, анимации (общий для всех страниц)
css/layout.css          адаптивная сетка, общая шапка и подвал, модули mod_*, терминал, бейджи
css/pages.css           микро-взаимодействия (hover/active), главная, карточки и HUD-загрузки, формы,
                        кабинет, терминал-оверлей, баннеры, HUD-тосты, классы настроек HUD
js/ui-effects.js        ядро: настройки HUD, звуки, сессия, экран загрузки, виджеты, телеметрия,
                        скрытый терминал, вкладки, модалки, тосты, меню; данные PROJECTS, SERVERS, DOCS;
                        API window.NEXUS
js/pages.js             логика страниц: каталог и симуляция загрузок (Downloads), окно «Подробнее»,
                        кабинет (серверы, логи, сборки, настройки), вход и регистрация
assets/                 шрифты, иконки, звуки, тема, augmented-ui (см. assets/ATTRIBUTION.md)
LICENSE                 GPL-3.0
```

Страница определяется атрибутом `<body data-page="home|projects|dashboard|auth">`.

## Авторизация (демо)

Бэкенда нет: вход демонстрационный. Любой логин (3–24 символа) или email и пароль от 6 символов
подходят. В `localStorage` (ключ `nx_session`) хранится **только профиль** — позывной, email,
ID, уровень допуска, история загрузок. Пароль не сохраняется и никуда не отправляется.

| Код доступа | Уровень |
|-------------|---------|
| — (пусто) | 2 · MEMBER |
| `PLAYTEST` | 3 · PLAYTESTER (закрытый тест BASTION) |
| `NEXUS-DEV` | 4 · DEVELOPER (dev-снапшоты, все сборки) |

Неверный код → звук `denied.wav` и баннер ACCESS DENIED. Настройки HUD хранятся в `nx_settings`.

## Звуки и отклик интерфейса

Звуки eDEX-UI включены по умолчанию и начинают играть после первого клика или нажатия клавиши
(так требуют браузеры). Громкость мягкая; выключить можно кнопкой `SFX` в шапке, командой `sfx off`
или в «Настройках HUD». Кнопки, вкладки и карточки реагируют на наведение и нажатие (подсветка рамки,
сдвиг, смена индикатора); вход, загрузки и изменения настроек подтверждаются HUD-тостами в углу.

## Скрытый терминал

Нажмите `~` (на русской раскладке — `Ё`) или маленькую иконку терминала в шапке / подвале на любой
странице. `Esc` или повторное `~` закрывают окно. Команды: `help`, `projects`, `open <id>`, `status`,
`servers`, `syslog`, `login`, `register`, `logout`, `dashboard`, `home`, `whoami`, `neofetch`, `date`,
`echo`, `history`, `sfx on|off`, `credits`, `reboot`, `clear`, `exit`.

## Как поменять контент

* Проекты — массив `PROJECTS` в `js/ui-effects.js`: статус (`available` / `closed` / `dev`),
  нужный уровень допуска `access`, версия, размер, файл, требования и patch notes. Из него
  строятся карточки, окно «Подробнее», список сборок в кабинете и счётчик релизов.
* Серверы — массив `SERVERS`; для реального мониторинга замените тело `tickTelemetry()`
  на запрос к своему API.
* FAQ, правила и лицензия (ссылки в подвале) — объект `DOCS`.
* Коды доступа — `ACCESS_CODES`, уровни — `LEVELS` в `js/ui-effects.js`.
* Цвета темы — CSS-переменные `--color_r/g/b`, `--color_light_black`, `--color_grey`
  в `css/blade-theme.css`.

## Что адаптировано относительно eDEX-UI

* Размеры в `vh` пересчитаны через единицу `--u` (1vh при 1080p = 10.8px): пропорции как в
  оригинале, но страница скроллится.
* `position: absolute/fixed` колонок и терминала заменены на CSS Grid.
* Код Electron/Node.js (`require`, `fs`, `ipc`, `systeminformation`, `node-pty`, `xterm`) удалён,
  виджеты переписаны на браузерных API, остальные данные генерируются как демо.
* Лог загрузки встроен в JS, чтобы сайт работал через `file://` без `fetch`. Анимация показывается
  на главной один раз за сессию, пропускается по Esc / клику и отключается в настройках HUD или
  при `prefers-reduced-motion`.
