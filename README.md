# JBEAM — True Soft-Body Crash Simulator

Готовый симулятор в одном файле: **`index.html`** (открывать напрямую в браузере, нужен интернет для CDN three.js r160).

## Что внутри

* **Настоящая мягкая физика (Node/Beam, BeamNG-подобная архитектура).** Никакого rigid body у машины:
  кузов, подвеска, колёса и столкновения считаются решёткой точечных масс, соединённых балками.
  * 114–124 узла, 505–566 балок на автомобиль (лонжероны, клетка салона, зоны деформации, косынки, петли дверей, крепления капота/бамперов).
  * Балки: `restLength`, жёсткость в Н/м, XPBD-податливость, демпфирование; **пластическая деформация** (restLength необратимо меняется — металл остаётся мятым) и **разрушение** по пределу прочности.
  * 840 Гц: 14 подшагов × 60 FPS, фиксированный шаг 1/900 с.
* **Мягкий скиннинг кузова.** Каждая вершина оболочки (≈2700 треугольников: капот, крыша, стойки, борта, двери, багажник, стёкла, днище) привязана к 4 физическим узлам с барицентрическими весами — при скручивании рамы/сминании кузов гнётся и рвётся вместе с каркасом. Детали (бамперы, фары, решётка, двигатель, зеркала, сиденья, выхлоп) крепятся к узлам и улетают вместе с оторванными панелями.
* **Рентген JBeam (`B`)** — 3 режима: кузов → полупрозрачный кузов + живая сетка узлов/балок → только скелет. Балки окрашиваются по деформации: зелёный → жёлтый (натяжение) → красный (пластика здесь и сейчас) → фиолетовый (необратимо погнут) → балка исчезает (лопнула).
* **Node Grabber (`Ctrl` + ЛКМ)** — подсветка узлов, захват любого узла пружиной: поднять машину за угол крыши, вырвать капот, швырнуть кузов.
* **Три машины:** Bruckell Bastion (RWD маслкар), Ibishu Covet (FWD хэтчбек), Gavril D-Series (4WD рамный пикап) — разные массы, жёсткости, пределы прочности, подвеска и привод.
* **Полигон:** стальные столбы (V-образное сминание передка), бетонный клин, трамплин, диагональные волны и трасса скручивания, отбойники, гидравлический пресс на крышу (`F`), вторая машина с полным soft-body скелетом (навстречу, полный контакт узлов).
* **UI в стиле BeamNG:** схема повреждений по зонам, лог событий, телеметрия (узлы/балки/погнутые/порванные/перегрузка в G), slow-mo `T` (1.0× / 0.2× / 0.05×).

## Управление

`WASD` — вождение, `Space` — ручник, `B` — рентген, `T` — slow-mo, `R` — восстановить машину,
`C` — камера, `F` — пресс на крышу, `Ctrl`+ЛКМ — захват узла, ЛКМ-драг — орбита, колесо — зум.

## Исходники

`index.html` собран из `src/` (физика — `physics.mjs`, рендер — `render1.mjs`/`render2.mjs`, UI — `main.mjs`).
Пересборка: `python3 src/build.py`.
