# КРАСНЫЙ ШТОРМ — offline Soviet-setting FPS

Полностью офлайновый тактический шутер на Three.js (WebGL2) + Rapier3D. Физика и ИИ
живут в отдельных Web Worker'ах, рендер и UI — на главном потоке. Никаких CDN и сетевых
запросов в рантайме: все ассеты и манифест лежат в бандле.

## Запуск

```bash
npm install
npm run dev        # http://0.0.0.0:5173
```

Продакшн:

```bash
npm run build      # ассеты + tsc --noEmit + vite build  -> dist/
npm run preview    # http://0.0.0.0:4173
```

## Проверки

```bash
npm test           # vitest: движок + игровые сценарии (14 сценариев)
npm run test:ui    # vitest/jsdom: HUD и все экраны меню (3 сценария)
npm run test:bundle# проверка собранного dist: entry/css/worker/110 GLB
node tests/smoke.mjs && node tests/perf.mjs && node tests/longrun.mjs
```

## Управление

| Действие | Клавиша |
|---|---|
| Движение / присесть / лечь | WASD / Ctrl / Z |
| Бег, прыжок | Shift, Space |
| Огонь, прицел, перезарядка | ЛКМ, ПКМ, R |
| Гаджет, ближний бой | G, V |
| Взаимодействие (техника, ящики, M-COM) | E |
| Смена класса / оружия | 1–4 (в меню), колесо мыши |
| Карта / счёт / пауза | Tab, M, Esc |

Техника: E — занять место, W/S — газ/тормоз (у вертолёта — шаг-газ), A/D — поворот
(у вертолёта — педали), мышь — башня/циклический шаг.

## Структура

```
src/shared/   типы, константы, конфиги (оружие, техника, сложность), генератор карт
src/sim/      движок (ECS-подобный), воркер физики 60 Гц, протокол, геометрия ассетов
src/ai/       воркер ИИ: поведенческие деревья + NavMesh
src/render/   ядро рендера, загрузчик ассетов, эффекты, миникарта
src/game/     игровой цикл, вьюмодель, клиент симуляции, ввод
src/ui/       HUD, меню, настройки, стили
assets/       manifest.json (110 записей), asset-report.json, procedural/*.glb
tests/        vitest-сценарии + node-скрипты smoke/perf/longrun/prof
tools/        check-bundle.mjs
```

## Ассеты

`assets/manifest.json` — единственный источник правды: 110 записей с стабильными ID,
у каждой указан тип (`source` / `procedural` / `placeholder`) и путь к GLB. Реальные
модели из папки Google Drive автоматически перекрывают процедурные силуэты; при
отсутствии ассета загрузчик подставляет уникальный процедурный меш и не падает.
Аудит: `assets/asset-report.json` — PASSED, 0 дублей моделей между предметами.
